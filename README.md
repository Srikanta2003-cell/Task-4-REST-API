# 🚀 User REST API
A simple and beginner-friendly **REST API** built with **Node.js and Express.js** to perform CRUD operations on user data.

### 🛠️ Tech Stack
- **Node.js**
- **Express.js**
- **JavaScript**
- **JSON**
- **Postman**

### ✨ Features
- Create users
- View all users
- View user by ID
- Update user details
- Delete users
- JSON request & response handling

### 🔗 API Endpoints
| Method | Endpoint | Action |
|---|---|---|
| GET | `/api/users` | Get all users |
| GET | `/api/users/:id` | Get user by ID |
| POST | `/api/users` | Create user |
| PUT | `/api/users/:id` | Update user |
| DELETE | `/api/users/:id` | Delete user |

### ⚡ Run Locally
npm install
npm start
API runs at:
http://localhost:3000

### 🧪 Testing
Tested all CRUD operations using **Postman**.
